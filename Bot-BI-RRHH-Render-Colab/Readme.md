Bot BI RRHH - Parcial 5
Descripción

Este proyecto consiste en la creación de un Bot BI para Recursos Humanos utilizando Python, PostgreSQL, Render y Google Colab.

El bot permite consultar información sobre empleados, asistencia, nómina, desempeño y alertas mediante preguntas simples, facilitando el análisis de datos para la toma de decisiones.

Herramientas utilizadas

PostgreSQL

Google Colab
